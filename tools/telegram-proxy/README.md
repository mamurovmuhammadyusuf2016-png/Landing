# Enquiry relay

Ariza/заявка с сайта уходит в Telegram через этот воркер. Он существует
ради одной вещи: **токен бота не должен лежать в JavaScript страницы.**

Пока `CONFIG.formEndpoint` в `js/main.js` пустой, сайт шлёт заявки напрямую
в `api.telegram.org` и токен виден любому, кто откроет исходник страницы.
Что это позволяет постороннему:

- завалить ваш чат фальшивыми заявками, так что настоящие потеряются;
- писать от имени бота;
- **читать входящие заявки** через `getUpdates`, если у бота не настроен
  webhook — а в заявках имя, телефон и Telegram-хэндл человека.

Побочная выгода: воркер живёт на вашем домене, а `api.telegram.org`
в части узбекских сетей режется. Сейчас такие посетители попадают в
ручной сценарий и обычно уходят.

## Установка (примерно 10 минут, бесплатный тариф Cloudflare)

Нужен аккаунт Cloudflare и Node.js.

```bash
cd tools/telegram-proxy
npx wrangler login
```

Положите токен и chat id в секреты — в репозиторий они не попадают:

```bash
npx wrangler secret put BOT_TOKEN
npx wrangler secret put BOT_CHAT_ID
```

`BOT_TOKEN` — **новый** токен от @BotFather (старый скомпрометирован, см.
шаг 4). `BOT_CHAT_ID` — тот же, что сейчас в `js/main.js`: `1290205717`.

Публикация:

```bash
npx wrangler deploy
```

Wrangler напечатает адрес вида
`https://aoa-form.<ваш-субдомен>.workers.dev`.

---

## Подключение к сайту

1. В `js/main.js` впишите этот адрес:

   ```js
   formEndpoint: "https://aoa-form.<ваш-субдомен>.workers.dev/",
   ```

2. Пересоберите языковые версии и выложите:

   ```bash
   python3 tools/build-langs.py
   ```

3. Отправьте тестовую заявку с сайта и убедитесь, что она пришла в чат.

4. **Только после того, как заявка дошла**, закройте дыру:

   - удалите строки `botToken` и `botChatId` из `js/main.js`;
   - снова выполните `python3 tools/build-langs.py`;
   - в @BotFather: `/revoke` для старого токена.

   Порядок важен: пока шаг 3 не подтверждён, старый путь — единственный
   рабочий, и удалять его нельзя.

---

## Что делает воркер

- принимает `POST {"text": "..."}` только с `academy-of-arabic.uz`;
- ограничивает 5 заявками в минуту с одного IP;
- отбрасывает пустой текст и всё длиннее 4 КБ;
- пересылает в Telegram и отвечает только `{"ok": true|false}` —
  ответ Telegram наружу не отдаётся.

## Если Cloudflare не подходит

Файл — обычный `export default { fetch }`. Тот же код почти без правок
работает как Vercel Edge Function или Netlify Edge Function; токен там
кладётся в переменные окружения проекта. Важно лишь одно: токен живёт на
сервере, а не на странице.
